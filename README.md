# 机器学习课程设计 · 四个实验

刘禹豪 · 20245616 · 人工智能2403

[课程设计报告 Word](report/机器学习课程设计报告_20245616.docx) 已同步代码说明、实验四固定等权融合公式及运行附录，正文区分原实验成绩与发布版方法。报告对应的源码基线为 `142ba51`。

本仓库整理四个实验的源码、配置、运行说明和代码检查。数据、训练权重、预测结果和历史运行缓存单独存放，不随 Git 上传。

| 目录 | 实验 | 主要方法 |
|---|---|---|
| `task1_plants` | 植物分类 | DINOv2-Large、ConvNeXt-Base，开发集交叉验证与独立训练留出集 |
| `task2_fer` | 表情分类 | 三个 CNN、DINOv2 LoRA、HSEmotion、POSTER，分组五折 |
| `task3_fovea` | 中央凹定位 | ResNet18 粗定位、多尺度局部精定位、固定等权融合 |
| `task4_vessels` | 眼底血管分割 | U-Net / U-Net++、scSE、EMA、多尺度与翻转推理 |

每个目录提供自己的 README 和依赖文件。建议使用 Python 3.10，分别建立虚拟环境；PyTorch 与 torchvision 需按照 GPU 驱动安装匹配版本。正式训练需要 CUDA，表情分类的大模型训练建议有 24 GB 及以上显存。

数据按各目录说明放置。推理入口只接受图像、已训练模型和提交模板；模板中的目标列仅是占位符，不参与计算。训练指标只来自有标注训练数据的内部划分。实验三训练流程在完成每个训练折后生成无标签测试预测；其测试数据不参与损失、早停或指标计算。

## 整理范围

移除了本地测试答案评分、测试分数驱动的比较与选参入口、旧预测缓存依赖、报告自动拼接脚本和过期服务器路径。实验四采用发布版固定等权融合及 0.5 阈值，不继承历史阈值搜索或多轮结果。这一代码版本不附带历史成绩，也不声称已经重新训练复现历史提交。

运行检查：`python -m pytest tests -q`。检查使用临时合成图像，覆盖数据边界、模板占位符独立性、划分隔离、暖启动限制及输出编码。完整训练需要用户自行提供数据和官方预训练权重。
